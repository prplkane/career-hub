      3. 
              
    3. Start Career Hub with extension access:.\scripts\start_career_hub.ps1 -EnableExtension
      4. 
              
    4. Load your browser's generated unpacked directory in developer mode.outputs/browser_extensions/<browser>
      5. 
              
    5. Firefox and Safari: copy the exact origin shown in the popup and restart with -ExtensionOrigin..\scripts\start_career_hub.ps1 -ExtensionOrigin "<exact popup origin>"

          FAQ and troubleshootingStorage, connection, and error guidance.
          
    
            
    Where is my data stored?
    The active local Data Home is shown in Settings under Local data. Career Hub does not upload it.
    
            
    What if Google App Passwords is unavailable?
    Use manual .eml import. Do not weaken account security.
    
            
    Why can't the extension connect?
    Confirm Career Hub is running on port 8766 with extension access enabled, then reload the unpacked extension.
    
            
    Where can I inspect a failed step?
    Open Diagnostics and record the error code and run ID when reporting a reproducible issue.
