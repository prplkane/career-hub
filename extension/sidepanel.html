              What the assistant never does
              • The page is read only after a Review or Find action, and only in the main frame.
              • Never clicks Continue, Next, or Submit, and never fills a field that already has a value.
              • Never fills hidden, credential, file, demographic, or open-ended screening fields. Voluntary US answers stay one-field Copy only.
              • Exact-question matching only. Passwords, financial data, eligibility, compensation, uploads, EEO/demographic questions, job-specific prompts, and open-ended answers remain manual.
              • Values stay in memory while this panel is open; reusable answers persist only after an explicit save to your local Career Hub.
              No navigation or submission action is clicked for you.
